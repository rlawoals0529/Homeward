# Privacy

## What this preview does

The app serves static text and layouts. It has no memory editor, input form, upload endpoint, authentication, analytics, embedded media, remote fonts or persistent application storage. No personal-memory content exists in its fixtures.

Opening the app requests its files from the chosen host. The host can observe ordinary requests and may retain access logs. Browser history can retain routes. Public source code does not make browsing anonymous. No production deployment or hosting-log configuration has been performed.

## Future commitments requiring implementation review

No mandatory account or service verification. No default cloud upload or memory tracking. Explicit selection and preview before exporting a family file. Local storage without encryption is the current planning default, with a clear warning that browser data can be lost and device/profile access can expose it.

Backups will be necessary for recovery. Downloaded family files cannot be revoked remotely. Human content review precedes historical publication. These are planning constraints, not available functionality.

See VERIFICATION.md for the actual browser/network/storage checks performed on this foundation. No legal compliance or security certification is asserted.
