# Contributing

Discuss scope before extending this foundation. Use synthetic copy, never personal service records. Changes belong in a focused branch and PR; no automatic merge or deployment.

Use the Node version in .nvmrc and `npm ci --ignore-scripts`. Run `npm run check`, install the pinned Playwright browsers, then `npm run test:browser`. Describe the changed behavior and actual check results in the PR. Keep screenshots free of real personal data.

Reuse shared components and CSS tokens. Keep links descriptive, focus visible and controls usable with keyboard and touch. Automated accessibility checks do not replace assistive-technology testing.

New dependencies need a concrete use, exact versions, license review and a lockfile update. New assets need source, creator, license, permitted use and attribution in docs/CONTENT_SOURCES.md. Do not copy a seal, award, photograph or historical account on the assumption that government-related means unrestricted.

Original contributions are provided under the repository MIT license. Do not submit material you cannot license. Security concerns follow SECURITY.md rather than a public exploit report.
