# Security

Homeward is pre-release. Only the current foundation development line is maintained; there are no supported public releases or live service commitments.

Do not put vulnerabilities, secrets or personal documents in public issues. GitHub private vulnerability reporting is not claimed enabled. Until a private channel is confirmed, ask the maintainer for one using an issue containing only a request to report a vulnerability. Do not include exploit details there.

Through the agreed private channel, provide the affected revision, browser/OS, impact and a minimal synthetic reproduction. No promised response SLA or bug bounty exists.

The foundation has no user-data pipeline. Security headers, dependency advisories and tests reduce particular risks; they are not a security certification. See docs/THREAT_MODEL.md and docs/VERIFICATION.md. Revisit this reporting channel before any public deployment.
